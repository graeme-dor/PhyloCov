Workflow

How PhyloCov fits into phylodynamic and transmission pipelines

The site is designed as a front door for covariate discovery, variable justification, and reproducible handoff into downstream statistical or mechanistic models.

Phase A

Choose datasets and bands

Select from climate, topography, land-use, vegetation, population, and imported asset layers, then choose the relevant band or derived variable for the system of interest.

Phase B

Configure processing choices

Define region, country, temporal window, spatial resolution, and zonal summary settings so the extracted covariates match the downstream analytical design.

Phase C

Visualise and export outputs

Inspect interactive maps and summary outputs, then carry selected surfaces into environmental modelling or phylodynamic workflows with transparent provenance.

About

Designed for ecological covariate discovery in phylodynamics

Research context

PhyloCov is positioned as a discovery layer for climate and ecological variables that can support pathogen spread analysis, risk mapping, and integrated phylodynamic modelling.

Why this structure works

Separating the public website from the Earth Engine app reduces deployment friction, keeps the interface maintainable, and lets you present the science and the tool together.

Model-facing design

The wrapper site can carry dataset notes, methods, citations, changelogs, and app-specific guidance without overloading the Earth Engine interface itself.

Cite

Document datasets and platform provenance clearly

Users should cite both the PhyloCov platform and the original environmental datasets underlying any covariates exported for downstream analyses.

Replace this with a DOI-backed citation once the platform, manuscript, or software record is formally archived.

Dataset acknowledgements

PhyloCov currently surfaces environmental covariates through Google Earth Engine, including climate layers such as CHIRPS and TerraClimate, soil and terrain context, vegetation and land-cover products, population-density surfaces, and imported project assets such as suitability layers.

Any publication or report using exported covariates should cite the original dataset providers for the specific layers selected in addition to citing the PhyloCov platform itself.

Methods note

PhyloCov supports covariate extraction by allowing users to choose a dataset and band, define a region or country of interest, configure temporal windows and spatial resolution, and generate mapped outputs or zonal summaries for downstream phylodynamic and transmission analyses.

When reporting results, users should describe the ecological rationale for variable choice, the processing settings used, and any transformations applied after export.

Roadmap

Near-term platform direction

The current app focuses on ecological covariate exploration and preparation, with scope to expand into grouped covariates, pathogen-specific bundles, and tighter integration with future tools.

Expanded covariate library

Add broader collections of environmental surfaces, imported assets, and grouped covariate presets that align with common modelling use cases.

API and programmatic access

Expose more structured outputs and documented access patterns so PhyloCov can sit more cleanly inside reproducible analysis pipelines.

Related tools
